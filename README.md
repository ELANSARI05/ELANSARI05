## 🚀 Featured work

### 👁️ GazeFusion: gaze annotation for crowd research (Forschungszentrum Jülich)
A semi-automated annotation system that fuses wearable eye-tracking with overhead-camera trajectories to infer where participants look in pedestrian-crowd experiments. It reconstructs gaze in world coordinates, synchronizes device clocks, detects 3D gaze hits with occlusion handling, and uses YOLO and RTMPose to pre-fill annotations, cutting manual effort from weeks to hours.
`Python` `PySide6` `PyVista` `NumPy/SciPy` `Shapely` `YOLO` `RTMPose` `SQLite`

### 🎙️ Vox: real-time conversational voice agent (ARTEFACT)
A voice agent targeting sub-500 ms end-to-end latency in French, English and Arabic. Its streaming pipeline lets the speech-to-text, LLM and text-to-speech components be swapped independently, which makes benchmarking providers fast.
`Python` `asyncio` `WebSocket/WebRTC` `Faster-Whisper` `OpenAI Realtime API`

### 🤖 Promptly: AI agent marketplace (co-founder)
A multi-agent platform where a conversational orchestrator routes requests to specialized agents, built for non-technical users. 🥈 2nd best project at Startup Garage, UM6P Science Week 2026.

### 🌾 Multimodal LLM for agriculture
Fine-tuned a multimodal LLM on Moroccan agricultural data to analyze plant diseases from text and images.

### 📈 Churn prediction (ORA Technologies)
A predictive analytics application for user retention and churn detection, with ML models designed for proactive intervention.
